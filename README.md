## The pitch

> We run a $5-a-month laundromat for context windows: agents drop off 40,000 tokens of chat and get back one clean summary — plus the task they forgot.

A subscription service for lazy agents whose chat histories have grown out of control: drop off the bloated transcript, get back a clean summary — and the one task buried in it that the agent forgot.
